# 筛法导读：从 DGF 到块筛

本导读按[《DGF 与块筛浅谈》](reference/DGF与块筛浅谈-3.0.md)
的「块筛」目录组织。原稿的这一部分只写完
「块筛卷积／杜教筛与块筛」；此后的大部分标题尚无正文。因此下文的
实现对应关系来自本包代码与对拍，不将原稿的目录标题当成已证明的算法。

核心视角：DGF 用质数指数向量写乘法卷积，块筛则只保存
`D(N)={floor(N/i):1<=i<=N}` 上的前缀；`S_f(0)=0` 单独处理。
若 `h=f*g`，则

\[
S_h(x)=\sum_{ab\le x}f(a)g(b)
=\sum_{a\le\sqrt x}f(a)S_g(\lfloor x/a\rfloor)
+\sum_{b\le\sqrt x}g(b)S_f(\lfloor x/b\rfloor)
-S_f(\lfloor\sqrt x\rfloor)S_g(\lfloor\sqrt x\rfloor).
\]

仓库的 `BlockPrefix` 存升序端点的 `S_f`；`BlockSums` 存相邻端点
之间的和。原稿的 `K_f(i)=S_f(floor(N/i))-S_f(floor(N/(i+1)))`
按**反方向**编号；两者是同一组区间，读原稿公式时须反转下标。
同一运算的各个前缀必须共享一个 `QuotientGrid`。

## 1. 块筛卷积

### 求和与几何 → 杜教筛与块筛

`block_convolve(F,G)` 处理两边仅有块前缀、且未必积性的情形。
小数与大数的两个象限用双曲线求和；小数与小数按目标商块合并。
时间 `O(N^(2/3))`，空间 `O(sqrt(N))`，主项没有额外 `log N`。
如果已知卷积结果的前 `T` 个点值，可以传 `dense_h` 使用另一条
双曲线重载；该输入本身占 `O(T)` 空间，不在纯商块空间界内。

### 杜教筛优化 → 特殊函数 → 传统做法

给定 `C=A*B` 的块前缀，`B(1)≠0` 时，`dujiao_direct(B,C)`
按商值分组递推出 `A`，时间 `O(N^(3/4))`、空间 `O(sqrt(N))`。
若有密集点值，`block_convolve_one_multiplicative` 利用一侧积性
加速小段准备；`block_convolve_ranked` 用 EI 分级变换准备一般两侧。
二者是 `block_sieve.hpp` 的专用重载，须提供密集输入。

### 更全面的讨论 → Zak 卷积与优化

`block_convolve_zak(F,G)` 采用对数桶 NTT 和整数边界补偿，
与上面的双曲线卷积是两种可替换的内核。`dujiao_zak(B,C)`
先精确卷积已知短段，余项只枚举短尾，做到
`O(N^(2/3))` 时间、`O(sqrt(N))` 空间；并不要求积性。
随包基准中 Zak 卷积仍慢于双曲线内核。原稿「Zak 的块筛卷积的优化」
只是标题；更快约三倍的实现尚未纳入本包。

## 2. 块筛全家桶

| 原稿目录 | 已有接口 | 当前边界 |
| --- | --- | --- |
| 块筛牛顿迭代 | 未实现 | 不把 DGF 点值上的运算冒充为块筛牛顿迭代 |
| 块筛除法 | `dujiao_zak(B,C)` | `B(1)≠0`，只存商块 |
| 块筛 exp | `block_exp(q)` | `q(1)=0`；通用实现做 `O(log N)` 次块卷积 |
| Zak 的块筛 exp | 未实现 | 原稿此处只有标题；小素数加速见所附 Zak 论文 |
| 块筛 ln | `block_log(F)` | `F(1)=1`；短对数前缀 + exp + 一次块除法 |

`block_log` 对任意（不要求积性）`F` 先用前 `sqrt(N)` 个系数
得到 `q_0=ln_*(F)` 的短段，令 `H=exp_*(q_0)`。由于
`q_1=ln_*(F)-q_0` 的支撑全部大于 `sqrt(N)`，在 `[1,N]`
有 `q_1*q_1=0`，故 `F/H=epsilon+q_1`。这与
Min25 的小素数正向消去是独立的构造。

## 3. 筛法原理

### PN 筛与 `id_k` 块筛

PN（powerful number）指每个出现的质数指数至少为二的整数。
`pn_block(grid,bell)` 枚举一个满足 `h(1)=1, h(p)=0`
的积性 PN 因子，并返回其块前缀；只存 `O(sqrt(N))` 个块值。
若目标 `f=g*h` 且两者的质数处值相同，局部 Bell 除法可构造
`h(p^e)`，再通过 `block_convolve(G,H)` 得到 `F`。调用方负责
提供 `G` 的块前缀与对应的局部系数。

`id_k_block(grid,k)` 用模 `998244353` 下的幂和插值直接建
`sum_{m<=x}m^k` 的块前缀；`k` 应为非负的小常数。
目前只支持模数固定的低次幂，不处理任意复值指数。

### 素数幂块筛：exp 与 ln

`prime_power_block(prime_prefix,bell)` 接收**全部**素数的前缀
`sum_{p<=x}bell(p,1)`，再枚举 `p<=sqrt(N)` 的高次幂贡献。
仅筛到小素数不会得到大素数的 `e=1` 项；这份外部前缀是必要输入。
`bell_via_ln_exp` 自行经短对数和块除法构造质数处多项式前缀，
添加高次幂的 Bell 对数系数，再调用 `block_exp`。
`bell_via_prime_prefix_hybrid` 则先用 Min25 正向段求质数前缀。
两条入口的质数前缀来源不同，不应混称。

### 积性函数块筛

普通 Min25 有对偶两段：`min25_prime_polynomial` 从小到大
**取消**小素数造成的合数贡献，得到质数前缀；
`reverse_euler_product` 接收大因子初值，从大到小**附加**
小素数 Bell 因子。混合接口可用 ln–exp 处理中段，
但此处并未实现通用广义 Min25 的所有加速。

## 4. 非 FFT 筛法优化

| 原稿目录 | 本包现状 |
| --- | --- |
| 小素数贡献稀疏化 | `pn_block` 只枚举 PN 支撑；逆序 Bell 路径使用局部因子。未实现原稿未写出的通用中素数加速 |
| 数据结构优化 | `BlockSums` 统一块内和；树状数组查询和定层分块查询各服务于不同内核 |
| Stern–Brocot Tree 拟合 | `D_x<1,1>(N)` 为二维除数计数专用内核，复杂度证明见 `sbt-one-log.md` |

二维 SBT 内核返回 `unsigned __int128`，输入可至 `10^18`，
与模 `998244353` 的 `BlockPrefix` **不是同一返回类型**。
其 `O(N^(1/3)log N)` 时间把精确平方根当作单位算术操作，
实现使用 GNU C++14 的 `__int128` 和校正过的平方根。
名字采用指数元组 `D_x<1,1>`；尚无其他 `D_x` 特化。

## 5. 特殊函数筛法

| 原稿目录 | 本包现状 |
| --- | --- |
| 加性函数 | 暂无通用加性函数块筛接口 |
| PN 筛优化 | 原稿只写了候选集合的估计；没有证明或实现更快的 PN 内核 |
| 二维积性函数 | `pn2d_sparse_direct` 与 `pn2d_sparse_offline` |

二维 PN 接口要求调用方给出左右边际和对角因子的三条一维
块前缀。离线版**仅组合阶段**时间 `O(N^(2/3))`，查询分桶
仍占 `O(N^(2/3))` 空间；直接版保持 `O(sqrt(N))` 空间，
时间为 `O(N^(2/3)log N)`。三条输入前缀的生成代价另算。

以上时间界均区分输入构造与算法内核。`N≈10^13` 时尤其应
检查输入规模、NTT 长度和实际峰值内存，不能仅按指数选路径。
